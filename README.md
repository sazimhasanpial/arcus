## ✨ Features

### 🎨 Theme & Multi-Currency Engine
- **Dark & Light Mode**: Instant toggle with persisted preference.
- **5 Brand Accent Themes**: Switch effortlessly between:
  - *Cyber Indigo* (Default)
  - *Neo Emerald* (Fresh)
  - *Crimson Pulse* (Vibrant)
  - *Solar Gold* (Warm)
  - *Quantum Cyan* (Electric)
- **Real-Time Currency Switcher**: Seamless conversion across USD ($), BDT (৳), EUR (€), and GBP (£).

### 🔍 Interactive Storefront & Navigation
- **Sticky Modern Header**: Live search input with instant clear, category filtering pills (All, Electronics, Apparel, Accessories, Home), and dynamic sorting (Featured, Price Low-to-High, Price High-to-Low, Highest Rated).
- **Flash Sale Banner**: Real-time ticking countdown timer with one-click coupon copying (`ARCUS20`).
- **Quick-View Modal**: Image gallery, variant selection, full spec sheet, and instant "Buy Now".
- **Side-by-Side Spec Comparison**: Compare up to 3 products across weight, battery, connectivity, material, and warranty.

### 🛒 Slide-Over Cart & Loyalty System
- **LocalStorage Persistence**: Cart and wishlist items persist across sessions.
- **Free-Shipping Progress Meter**: Dynamic meter towards the $200 free priority air cargo threshold.
- **Discount & Promo Engine**: Support for `ARCUS20` (20% off) and `VIP50` (25% off).
- **VIP Loyalty Points Redemption**: One-click redemption of Platinum VIP points for instant checkout credit.

### 💳 Frictionless Checkout & Payment Gateways
- **1-Click Demo Auto-Fill**: Auto-populates verified VIP profile details for Sazim Hasan Pial.
- **Interactive 3D Live Credit Card**: Updates cardholder name, formatted card number, expiry, and flips 180° to display CVV when the security code field is focused.
- **Multiple Gateways**:
  - Credit / Debit Card (with 3D live interactive card)
  - **bKash** (Direct mobile banking flow)
  - **Nagad** (Digital wallet flow)
  - **BNPL 4-Installment Calculator** (4 interest-free bi-weekly split payments)
  - Apple Pay / Google Pay (1-tap biometric simulation)
  - Cash on Delivery (COD)
- **Official Printable Tax Invoice**: Generated on completion with print/PDF export and order verification.

### 👤 VIP Customer Hub & Package Tracker
- Pre-authenticated profile for **Sazim Hasan Pial** (`sajimhasan12@gmail.com`) with **Platinum Tier** status and 2,450 points.
- **Interactive 5-Step Live Package Tracker**: With an interactive *"Simulate Next Delivery Step"* button to test delivery workflows from order placement to doorstep handover.

### 🤖 AI Shopping Concierge
- Floating bottom-right AI assistant with quick prompts, smart product recommendations, coupon dispenser, and live order tracking.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation
```bash
# Clone the repository
git clone https://github.com/sazimhasanpial/arcus.git
cd arcus

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

### Deploy to GitHub Pages
```bash
npm run deploy
```
